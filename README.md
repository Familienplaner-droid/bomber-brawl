# Boomtown Brawl

Prototyp eines Handy-Spiels: Bomben legen wie im Klassiker, schießen und Helden wie in Brawl Stars, dazu Stockwerke, Flüche und Lüftungsschächte. 12 Spieler, jeder gegen jeden, gegen Bots.

Der Prototyp läuft komplett im Browser, auch auf dem Handy. Auf dem Handy wird quer gespielt. Er dient dazu, das Spielprinzip zu testen, bevor die echte App gebaut wird.

## Spielen

**Online:** über GitHub Pages (Link steht oben rechts im Repository unter „About“, sobald Pages aktiviert ist).

**Lokal:** `index.html` herunterladen und im Browser öffnen. Es wird nichts installiert.

## Steuerung

| Aktion | Handy | PC |
|---|---|---|
| Laufen | linke Bildschirmhälfte ziehen | WASD oder Pfeiltasten |
| Schießen (zielt automatisch) | blauer Knopf oder rechts tippen | J |
| Bombe legen | oranger Knopf | Leertaste |
| Super-Fähigkeit | gelber Knopf, wenn voll | E |
| Waffe wechseln | heller Knopf | Q |

## Inhalt

- **Helden:** Rex (Megabombe), Lumi (Leuchtfeuer), Mimik (Tarnung als Kiste), Schatten (Licht aus)
- **Level:** Klassik-Labyrinth, Trümmerfeld, Absturz (3 Stockwerke), Sternejagd (2 Minuten, Sterne sammeln)
- **Power-ups:** Reichweite, Bomben, Tempo, Heilung, Abprall-Bomben, Flüche
- **Lüftungsschächte:** bringen dich zu einem anderen Schacht derselben Ebene
- **Story-Modus:** drei Geschichten mit je vier Kapiteln (Die verschüttete Stadt, Das große Turnier, Der Saboteur), Fortschritt wird im Browser gespeichert
